# 🔊 Python Text-to-Speech (TTS) App

This is a simple yet powerful Text-to-Speech (TTS) application built using Python. It converts written text into spoken words using the pyttsx3 library.

## 🚀 Features
- Convert text to speech instantly
- Adjustable speech rate (speed)
- Volume control
- Voice selection (male/female if available)
- Interactive command-line interface
- Error handling for invalid input

## 🧠 How It Works
- The program initializes a TTS engine using pyttsx3
- User inputs text via the terminal
- The engine processes and speaks the text aloud
- The loop continues until the user exits

## 🛠️ Technologies Used
- Python
- pyttsx3 (offline TTS engine)
